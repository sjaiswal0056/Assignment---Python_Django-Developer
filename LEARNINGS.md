# What I Learned in This Assignment

## 1. Box Selection
Selection of the box should take into account not only its volume but also the length, width, height, and weight of items.

## 2. Cost Optimization
Choosing the best box allows one to minimize packaging cost by taking into account not only the price of the box but also its volume.

## 3. Django and Python
My knowledge of Django and Python improved as I separated the packing algorithm from models, which was helpful in testing the program.

## 4. Testing
I discovered the importance of testing in order to check whether different elements of the application work properly and avoid mistakes.

## 5. Handling Edge Cases
In some cases, an order might not fit into one box. In such cases, there is a need to handle such orders and to find items that need special packaging.

## 6. Future Improvements
The packing algorithm needs to be optimized and more cases need to be tested. It would also be great to simplify the application for the warehouse workers.
